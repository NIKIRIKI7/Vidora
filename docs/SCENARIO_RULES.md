# Гайд по написанию сценария (SCENARIO.md)

`SCENARIO.md` — единственный источник правды (SSOT) для проекта в Vidora. Он описывает, что будет в видео: текст, визуальный ряд, тайминги, цвета, переходы.

## 1. Frontmatter (YAML-шапка)

Между `---` задаются глобальные параметры проекта:

| Поле | Обязательно | Описание |
|------|-------------|----------|
| `title` | да | Название видео (используется в метаданных и имени файла) |
| `description` | нет | Описание для YouTube/описание |
| `tags` | нет | Список тегов (через запятую в `[]`) |
| `fps` | нет | Кадров в секунду: `24`, `30`, `60` (по умолчанию `30`) |
| `animation_style` | нет | Стиль анимации: `screencast`, `motion_cut`, `cinematic`, `talking_head` |
| `transitions` | нет | Список переходов между сценами |
| `primary`, `secondary`, `accent`, `background`, `surface`, `text` | нет | HEX-цвета палитры |

**Пример:**

```yaml
---
title: "Обзор RTX 5090"
description: "Полный разбор производительности и нововведений"
tags: [tech, review, rtx5090]
animation_style: motion_cut
fps: 60
transitions: [fade, slide_left]
primary: "#ddb7ff"
secondary: "#4fdbc8"
background: "#0b1326"
surface: "#171f33"
accent: "#ffb4ab"
text: "#dae2fd"
---
```

### Цветовая палитра

6 цветов управляют единым стилем всего видео:

| Ключ | Назначение |
|------|------------|
| `primary` | Главный цвет: заголовки, акценты, кнопки |
| `secondary` | Второстепенный: субтитры, иконки |
| `accent` | Акцентный: предупреждения, выделения |
| `background` | Фон сцены |
| `surface` | Поверхности: карточки, панели |
| `text` | Основной текст |

Если цвета не указаны, используются дефолтные тёмные.

### Переходы (transitions)

Список переходов между сценами. Если сцен больше, чем переходов, последний повторяется.

| Значение | Тип |
|----------|-----|
| `fade` | Плавное затухание |
| `slide_left` | Свайп влево |
| `slide_right` | Свайп вправо |
| `slide_up` | Свайп вверх |
| `zoom` | Наезд камеры |
| `glitch` | Цифровые помехи |
| `cross_zoom` | Кросс-зум |

## 2. Структура сцены

Сценарий состоит из **сцен**, каждая определяется заголовком в квадратных скобках с таймкодом:

```
[Название сцены] (MM:SS:MM)
```

Таймкод задаёт смещение начала сцены от начала видео (часы:минуты:секунды:сотые или минуты:секунды).

Внутри сцены идут **фрагменты** — строки текста с визуальными ремарками.

### Фрагмент

```
*(Визуальная ремарка для AI/Remotion)* Текст суфлёра, который озвучивает TTS.
```

Каждая строка — отдельный фрагмент сцены. Структура:
- `*(...)*` — визуальное описание кадра для генерации Remotion-компонента
- `Текст после скобок` — озвучивается TTS (может быть пустым для чистого B-roll)

**Пример сцены:**

```md
[Интро] (00:00:00)
*(Крупный план: разбитое яйцо стекает в миску)* Сегодня я покажу вам рецепт идеального омлета.
*(Иконки: яйцо, молоко, масло)* Вам понадобятся: яйца, молоко и сливочное масло.
```

### Таймкод фрагмента (опционально)

Можно указать таймкод прямо в визуальной ремарке:

```
*(00:05 - 00:12: Крупный план рук)* Текст фрагмента.
```

Таймкод автоматически распознаётся и используется для синхронизации.

## 3. Визуальные ремарки

Правила хорошей ремарки:

- **Конкретная**: `*(Крупный план: логотип появляется слева)*` — хорошо
- **Размытая**: `*(Что-то крутое)*` — плохо
- **Описывает кадр, а не эмоцию**: `*(Текст глитчит, затем стабилизируется)*` — хорошо
- **Описывает ощущение**: `*(Эпично)*` — плохо

### Типы ремарок

```
*(Экран: ...)*           — скринкаст/интерфейс
*(Крупный план: ...)*    — деталь, лицо
*(Средний план: ...)*    — человек/объект в кадре
*(Анимация: ...)*        — абстрактная анимация
*(Схема: ...)*           — диаграмма, схема
*(Текст на экране: ...)* — просто текст на экране
*(Таймер: ...)*          — обратный отсчёт
*(B-roll: ...)*          — дополнительные кадры
```

### Продвинутые ремарки

Для сток-кадров (Pexels):
```
*(B-roll: человек работает за ноутбуком)* Текст фрагмента.
```

Таймкод вручную:
```
*(00:15 - 00:20: Городской пейзаж, таймлапс)* Текст.
```

Пустой TTS (чистый B-roll):
```
*(10-секундный таймлапс заката)*
*(Музыка нарастает, экран затемняется)*
```

## 4. Полный пример

```md
---
title: "Как приготовить идеальный омлет"
description: "Короткое кулинарное видео с пошаговым рецептом"
tags: [кулинария, завтрак, омлет]
animation_style: screencast
fps: 30
primary: "#ddb7ff"
secondary: "#4fdbc8"
background: "#0b1326"
surface: "#171f33"
accent: "#ffb4ab"
text: "#dae2fd"
---

[Интро] (00:00:00)
*(Крупный план: разбитое яйцо стекает в миску, замедленная съёмка)*
Сегодня я покажу вам рецепт идеального омлета. Всего три ингредиента, пять минут.
*(Схема: иконка яйца, молока, масла)*
Вам понадобятся: яйца, молоко и сливочное масло. Всё.

[Приготовление смеси] (00:00:12)
*(Средний план: руки взбивают яйца венчиком)*
Разбейте два яйца в глубокую миску. Добавьте две столовые ложки молока.
*(Таймер: обратный отсчёт 30 секунд)*
Взбивайте вилкой или венчиком около 30 секунд, до однородности.
*(Текст на экране: «Щепотка соли — обязательно»)*
Посолите и поперчите по вкусу.

[Жарка] (00:00:28)
*(B-roll: масло тает на сковороде)*
Разогрейте сковороду на среднем огне и растопите масло.
*(Анимация: смесь выливается и распределяется)*
Вылейте смесь и равномерно распределите по дну сковороды.
*(Таймер: 2:00 → 0:00)*
Готовьте 2 минуты, пока края не схватятся, а середина останется жидковатой.

[Сворачивание и подача] (00:00:44)
*(Средний план: лопатка сворачивает омлет пополам)*
Аккуратно сверните омлет лопаткой пополам.
*(Крупный план: омлет на тарелке, пар поднимается)*
Переложите на тарелку. Сверху можно добавить зелень или тёртый сыр.
*(Финальный кадр: омлет с зеленью, аппетитный ракурс)*
Готово! Проще некуда.
```

## 5. Рекомендации

### Длительность
- Фрагмент с текстом: ~3 секунды на строку текста
- Фрагмент без текста (B-roll): укажите таймкод или длительность в ремарке
- Сцена: 10–30 секунд. Оптимальная длина видео: 1–3 минуты

### Разметка
- Между сценами оставляйте пустую строку
- Таймкоды сцен — с шагом 10–15 секунд (можно приблизительно, точные расставит WhisperX)
- Для Shorts/Reels (9:16) — делайте текст короче и динамичнее

### Что делает хороший сценарий
- Первая сцена — хук, захватывает внимание за 3 секунды
- Каждая сцена — один микро-вывод
- Текст для TTS должен быть читаемым вслух (без сложных конструкций)
- Ремарки описывают *то, что видно на экране*

## 6. Форматы и разрешения

Формат выбирается в интерфейсе Vidora при создании проекта:

| Формат | Разрешения | Куда |
|--------|-----------|------|
| `16:9` | 1920×1080 (HD), 2560×1440 (2K), 3840×2160 (4K) | YouTube, Vimeo |
| `9:16` | 1080×1920 (HD), 1440×2560 (2K), 2160×3840 (4K) | Shorts, Reels, TikTok |

В YAML-шапке формат не указывается — он задаётся в UI при создании проекта.
